# Security policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please report it privately through GitHub: **Security → Report a vulnerability** on this
repository (or <https://github.com/hamer1818/dpi-dashboard/security/advisories/new>).
Do not open a public issue for it.

Include what you found, how to reproduce it, and the version and system you used. You
will get an answer within a week; a fix and an advisory follow once the issue is
confirmed.

## Scope

In scope: DPI Dashboard itself — the app, the setup helpers in
`src/dpi_dashboard/assets/`, the install scripts and the release workflow.

Out of scope, please report upstream: zapret ([bol-van/zapret](https://github.com/bol-van/zapret)),
WinDivert ([basil00/WinDivert](https://github.com/basil00/WinDivert)), Qt / PyQt6.

See the Security section of the [README](README.md#security) for what runs with
administrator rights and the known limits.
